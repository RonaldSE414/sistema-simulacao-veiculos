# 🚗 Sistema de Simulação de Veículos

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

## Objetivo
Criar um sistema de simulação de veículos utilizando conceitos de:
- Encapsulamento
- Herança
- Polimorfismo
- Sobrecarga
- Sobrescrita

---

## Estrutura do Projeto

- `Veiculo` (classe base)
- `Carro`, `Moto`, `Caminhao` (herança)
- `Garagem` (armazenamento)
- `SimuladorDeTrafego` (simulação)

---

## Funcionalidades

- Criar diferentes tipos de veículos
- Acelerar e frear (sobrecarga)
- Abastecer com diferentes tipos de combustível
- Simular tráfego
- Interação entre veículos
- Tratamento de erros (garagem cheia, sem combustível)
